# Core development records

Detailed logs, qualification records, generated figures and raw results live
outside this checkout in `../warpSPHDevelopment/core/`, relative to the
repository root. Its `README.md` and `manifests/migration-2026-10-16.json`
describe the layout and checksum-verified migration.

The shared `warpSPHDevelopment` directory is backed up manually. Each project
uses its own child directory; this repository uses `core`.

The checked-in [development artifact policy](../docs/development-artifacts.md)
contains the current qualification summary, configuration and regeneration
commands. The [repository plan](../../REPOSITORY_PLAN.md) retains the current
capability priorities. The original detailed plan is preserved in the archive.
